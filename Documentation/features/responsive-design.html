Responsive & design cohérent

v1.1.0 Mis à jour le 2026-11-16 Stable

Description

Design system unifié (tokens couleurs, typo fluide, espacements) et responsive desktop / tablette / mobile. Palette de marque bleue (#1E3A8A), fonds #EEF2FE / #FAFBFD, niveaux de risque dédiés.

Cas d'usage

  • Affichage correct du hero collage sur écrans moyens et petits
  • Menu mobile plein écran avec fermeture Escape / clic extérieur
  • Grille features (5 cartes) alignée sans carte orpheline
  • Démo produit avec onglets scrollables sur mobile

Breakpoints

CSS 
/* ≥ 1101px  — 5 features en grille 6 colonnes

   ≤ 900px   — menu hamburger, stacks 1 colonne
   ≤ 640px   — CTA pleine largeur, 1 témoignage
   ≤ 380px   — stats / footer en colonne */

Sécurité

  • ✅ Aucun secret dans le front
  • ✅ Formulaire démo : pas d'envoi réseau (front-only)
  • ✅ Consentement cookies stocké en localStorage uniquement
  • ⚠️ Brancher le formulaire sur un endpoint sécurisé avant production
