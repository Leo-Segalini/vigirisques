Formulaire Brevo (sans BDD)

v1.4.1 Mis à jour le 2026-11-19 Stable

Principe

Le front appelle un Cloudflare Worker si formApiUrl est renseigné. Sinon, fallback mailto:contact@vigirisques.fr — la prod reste utilisable sans Cloudflare. Avec Worker, la clé Brevo reste côté serveur.

Fichier .env (racine)

  1. cp .env.example .env
  2. Renseigner BREVO_API_KEY, CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID
  3. Optionnel : FORM_TO_EMAIL / FORM_FROM_EMAIL
Environnement
BREVO_API_KEY=xkeysib-…
CLOUDFLARE_API_TOKEN=…
CLOUDFLARE_ACCOUNT_ID=…
FORM_API_URL=

Déploiement

  1. Vérifier l'expéditeur contact@vigirisques.fr dans Brevo.
  2. cd brevo-worker && npm i
  3. À la racine : npm run deploy:form — lit le .env, déploie le Worker, pousse le secret Brevo, met à jour config.js
  4. Pousser le site GitHub Pages (dont config.js avec formApiUrl)
