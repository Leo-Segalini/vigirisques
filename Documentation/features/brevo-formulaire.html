Formulaire Brevo (sans BDD)

v1.4.0 Mis à jour le 2026-11-19

Principe

Le front appelle un Cloudflare Worker. Le Worker détient BREVO_API_KEY et envoie un e-mail transactionnel. Aucune base de données.

Déploiement

  1. Créer une clé API Brevo (SMTP transactionnel).
  2. Vérifier l'expéditeur contact@vigirisques.fr dans Brevo.
  3. cd brevo-worker && npm i && npx wrangler login
  4. npx wrangler secret put BREVO_API_KEY
  5. npm run deploy → récupérer l'URL *.workers.dev
  6. Coller l'URL dans config.js → formApiUrl
  7. Pousser le site GitHub Pages

Sécurité

  • ✅ Clé API hors du front
  • ✅ CORS restreint aux origines autorisées
  • ✅ Validation serveur + honeypot
  • ⚠️ L'e-mail expéditeur doit être vérifié chez Brevo
