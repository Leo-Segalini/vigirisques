Architecture

v1.1.0 Mis à jour le 2026-11-16

Structure

Arborescence
vigirisques/
├── index.html      # Landing page
├── styles.css      # Design system + responsive
├── script.js       # Interactions (nav, démo, modal, cookies)
├── README.md
└── Documentation/  # Docs HTML

Principes

  • Statique : aucun build, ouvrir index.html ou servir en HTTP local
  • Tokens CSS en :root comme source de vérité visuelle
  • Surfaces en alternance --surface-0 … --surface-3
  • JS vanilla sans dépendance
